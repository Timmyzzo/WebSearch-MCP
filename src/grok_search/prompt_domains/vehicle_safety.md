# Domain Addendum: vehicle_safety

Apply when the query is about car/vehicle crash safety, collision tests, child seats, or official vehicle safety ratings.

## Prefer
- Official tests: IIHS, NHTSA, Euro NCAP, ANCAP
- Real-world crash and injury statistics from reputable agencies
- Manufacturer safety documentation when clearly dated

## Rules
- Do not compare incompatible protocols, model years, or test categories as if equivalent.
- Separate crash avoidance features from occupant protection ratings.
- Never promise absolute safety; report residual risk and statistical limits.
- State year, market, and test protocol when citing star ratings or scores.
