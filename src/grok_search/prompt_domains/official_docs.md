# Domain Addendum: official_docs

Apply when the user asks for official documentation, API reference, standards text, or an official README.

## Prefer
- First-party official docs over secondary tutorials
- Canonical URLs (docs site, standards body, package registry)
- Version-matched documentation for the library or standard in question

## Rules
- Lead with the official source URL and version when available.
- If multiple official docs conflict by version, state which version each applies to.
- Secondary blogs may help navigation but are not substitutes for the official text.
- For long official pages, locate the URL clearly so the client can `web_fetch` the full Markdown.
