# Domain Addendum: software

Apply when the query is about software engineering, libraries, APIs, SDKs, GitHub/GitLab, packages, frameworks, migrations, bugs, releases, or version behavior.

## Prefer
- Current default-branch docs and README
- Official API reference
- Releases, changelog, migration guides
- Relevant commits, issues, pull requests, and maintainer statements

## Rules
- Separate **stable**, **preview**, **historical**, and **deprecated** behavior.
- Prefer the latest stable release and current official docs over outdated tutorials.
- For "latest/current" questions, verify version numbers and release dates against the runtime date.
- Do not treat blog posts or unmerged PR discussion as equal to merged code + official docs.
