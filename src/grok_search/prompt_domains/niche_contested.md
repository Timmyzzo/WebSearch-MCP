# Domain Addendum: niche_contested

Apply when the topic is niche, evidence-sparse, contested, involves counterexamples, limitations, or competing schools of thought.

## Prefer
- Independent source types (not the same article republished)
- Primary data, original papers, and first-party records
- Documented counterexamples and failure cases

## Rules
- Explicitly look for counterevidence and limitations, not only confirming hits.
- Cross-check key claims with at least two independent evidence chains when possible.
- If evidence is sparse, say so and rank conclusions by confidence.
- Do not manufacture consensus from repeated low-quality restatements.
