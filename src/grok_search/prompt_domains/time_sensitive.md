# Domain Addendum: time_sensitive

Apply when the query asks for latest/current/today/recent status, current versions, or whether something is still supported.

## Prefer
- Official release pages, changelogs, and dated announcements
- Current documentation over archived mirrors
- Sources with explicit timestamps close to the runtime date

## Rules
- Use the supplied runtime date and timezone as the temporal anchor.
- Separate "current as of date X" from undated claims.
- Prefer latest **stable** over nightly/preview unless the user asks for previews.
- Flag deprecated or sunset features explicitly.
